遷移概覽

遷移目標

項目 舊環境（Linux） 新環境（macOS）
機器 Linux 伺服器 Mac Mini
OpenClaw 路徑 /root/.openclaw /Users/adai/.openclaw
用戶 root adai
Telegram Bot 新 Bot 原有 Bot（保留）

主要挑戰

⚠️
硬編碼路徑問題：workspace 中的多個腳本使用絕對路徑 /root/.openclaw，需要批量替換為 /Users/adai/.openclaw。
⚠️
操作系統差異：Chrome 路徑不同、服務管理方式不同（systemd → launchd）、Python 環境可能不同。
🚨
Bot Token 衝突：兩台機器不能同時使用同一個 Telegram Bot Token，必須按策略配置。

為什麼不能共用 Bot？

  • Telegram 只允許一個 Webhook/Long polling 連接 per Bot
  • 兩個實例會互相搶消息，導致消息丟失或重複
  • 可能觸發 Telegram 的速率限制，導致帳號被封

新 Bot 創建步驟（在 Linux 伺服器上）

  1. 在 Telegram 中搜索 @BotFather
  2. 發送 /newbot 命令
  3. 按提示設置 Bot 名稱和用戶名（如 @frank_xiaoer_backup_bot）
  4. 記錄下 Bot Token（格式：123456789:ABCdefGHIjklMNOpqrsTUVwxyz）
  5. （可選）設置 Bot 頭像和描述以區分
💡
提示：新 Bot 用於 Linux 伺服器過渡期，待 Mac Mini 完全穩定後，可以選擇停用 Linux 上的 OpenClaw。

第一階段：準備工作

1.1 在 Mac Mini 上安裝 OpenClaw

# 安裝 OpenClaw（根據官方最新文檔）
curl -fsSL https://openclaw.ai/install.sh | bash

# 確認安裝路徑
ls -la ~/.openclaw/
# 應該是 /Users/adai/.openclaw

1.2 安裝依賴軟件

# 安裝 Homebrew（如果還沒有）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 安裝必要工具
brew install python@3.11 git rsync

# 安裝 gunicorn（用於 News API）
pip3 install gunicorn flask

# 安裝 Google Chrome（瀏覽器自動化需要）
brew install --cask google-chrome

1.3 為 Linux 創建新 Bot

按照上方「Bot 配置策略」部分的步驟，在 Telegram 中創建新 Bot，並記錄 Token。

2

第二階段：數據遷移

2.1 在 Linux 上打包數據

# 進入 root 家目錄
cd /root

# 方法 A：打包為壓縮檔
tar czvf openclaw-backup-$(date +%Y%m%d).tar.gz .openclaw/

# 方法 B：直接使用 rsync 傳輸（推薦，更快）
rsync -avz --progress /root/.openclaw/ adai@mac-mini-ip:/Users/adai/.openclaw-temp/

2.2 傳輸到 Mac Mini

如果使用壓縮檔方式，將檔案傳輸到 Mac：

# 在 Mac Mini 上執行
scp root@linux-server-ip:/root/openclaw-backup-*.tar.gz ~/

# 解壓
cd ~
tar xzvf openclaw-backup-*.tar.gz

# 如果用了 rsync，直接移動
mv ~/.openclaw-temp ~/.openclaw

2.3 備份原始配置

# 在 Mac Mini 上備份，以防萬一
cp -r ~/.openclaw ~/.openclaw-backup-before-migration

第三階段：路徑替換（關鍵步驟）

3.1 批量替換硬編碼路徑

🚨
警告：執行前務必確認已經備份！ 
# 進入 workspace 目錄
cd /Users/adai/.openclaw/workspace

# 查找所有包含 /root/.openclaw 的文件
grep -r "/root/.openclaw" . --include="*.py" --include="*.sh" --include="*.json" --include="*.md"

# 批量替換（macOS 的 sed 語法與 Linux 略有不同）
find . -type f \( -name "*.py" -o -name "*.sh" -o -name "*.json" -o -name "*.md" \) \
  -exec sed -i '' 's|/root/.openclaw|/Users/adai/.openclaw|g' {} +

# 同時替換 /root/project（如果有引用外部項目）
find . -type f \( -name "*.py" -o -name "*.sh" \) \
  -exec sed -i '' 's|/root/project|/Users/adai/project|g' {} +

3.2 驗證替換結果

# 檢查是否還有遺漏的 /root/ 路徑
grep -r "/root/" . --include="*.py" --include="*.sh" | grep -v ".bak"

# 應該沒有輸出，或只有註釋中的

3.3 修改主配置文件

編輯 /Users/adai/.openclaw/openclaw.json：

{
  "browser": {
    "enabled": true,
    "executablePath": "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome",
    "headless": true,
    "noSandbox": false,
    "defaultProfile": "openclaw",
    "profiles": {
      "openclaw": {
        "cdpPort": 18801,
        "color": "#FF4500"
      }
    }
  }
}
💡
注意：macOS 上不需要 noSandbox: true，這是 Linux 特有的需求。

3.4 需要修改的文件清單

文件類型 路徑示例 修改內容
Python 腳本 workspace/monitoring/*.py /root/ → /Users/adai/
Python 腳本 workspace/news-api/*.py /root/ → /Users/adai/
Python 腳本 workspace/scripts/*.py /root/ → /Users/adai/
Shell 腳本 workspace/ai-story/*.sh /root/ → /Users/adai/
Shell 腳本 workspace/news-api/*.sh /root/ → /Users/adai/
配置文件 openclaw.json Chrome 路徑更新

第四階段：Bot 配置

4.1 Mac Mini 配置（使用原有 Bot）

編輯 /Users/adai/.openclaw/openclaw.json，保持原有 Token 不變：

{
  "channels": {
    "telegram": {
      "enabled": true,
      "dmPolicy": "pairing",
      "bots": {
        "main": {
          "token": "[原有Bot的Token，保持不變]",
          "accountId": "main"
        }
      },
      "groups": {
        "-5144282791": {
          "requireMention": true,
          "allowFrom": ["*"]
        }
      }
    }
  },
  "dispatch": {
    "rules": [
      {
        "agentId": "main",
        "match": {
          "channel": "telegram",
          "accountId": "main"
        }
      },
      {
        "agentId": "xiaoer",
        "match": {
          "channel": "telegram",
          "accountId": "xiaoer"
        }
      }
    ]
  }
}

4.2 Linux 伺服器配置（使用新 Bot）

在 Linux 上編輯 /root/.openclaw/openclaw.json，更新為新 Bot Token：

{
  "channels": {
    "telegram": {
      "enabled": true,
      "dmPolicy": "pairing",
      "bots": {
        "main": {
          "token": "[新創建的Bot Token]",
          "accountId": "main_backup"
        }
      }
    }
  },
  "dispatch": {
    "rules": [
      {
        "agentId": "main",
        "match": {
          "channel": "telegram",
          "accountId": "main_backup"
        }
      }
    ]
  }
}
⚠️
重要：兩台機器的 accountId 必須不同，否則會導致路由混亂。

第五階段：服務遷移

5.1 創建 News API Launchd 服務

macOS 使用 launchd 替代 systemd。

創建文件 /Users/adai/Library/LaunchAgents/com.frank.news-api.plist：

<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" 
  "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.frank.news-api</string>
    
    <key>ProgramArguments</key>
    <array>
        <string>/usr/local/bin/gunicorn</string>
        <string>-w</string>
        <string>1</string>
        <string>-b</string>
        <string>127.0.0.1:8888</string>
        <string>--access-logfile</string>
        <string>-</string>
        <string>--error-logfile</string>
        <string>-</string>
        <string>app:app</string>
    </array>
    
    <key>WorkingDirectory</key>
    <string>/Users/adai/.openclaw/workspace/news-api</string>
    
    <key>EnvironmentVariables</key>
    <dict>
        <key>PATH</key>
        <string>/usr/local/bin:/usr/bin:/bin</string>
        <key>PYTHONPATH</key>
        <string>/Users/adai/.openclaw/workspace/news-api</string>
    </dict>
    
    <key>RunAtLoad</key>
    <true/>
    <key>KeepAlive</key>
    <true/>
    
    <key>StandardOutPath</key>
    <string>/Users/adai/.openclaw/logs/news-api.out</string>
    <key>StandardErrorPath</key>
    <string>/Users/adai/.openclaw/logs/news-api.err</string>
</dict>
</plist>

5.2 加載服務

# 創建日誌目錄
mkdir -p /Users/adai/.openclaw/logs

# 加載服務
launchctl load ~/Library/LaunchAgents/com.frank.news-api.plist

# 啟動服務
launchctl start com.frank.news-api

# 檢查狀態
launchctl list | grep com.frank.news-api

# 測試 API
curl http://127.0.0.1:8888/health

5.3 檢查 Cron 任務

OpenClaw 內部的 Cron 存儲在 /Users/adai/.openclaw/cron/jobs.json，檢查其中的路徑是否已正確更新。

第六階段：驗證測試

6.1 驗證腳本

創建並運行驗證腳本：

#!/bin/bash
# save as: verify-migration.sh

echo "=== OpenClaw 遷移驗證 ==="

# 1. 檢查路徑
echo "1. 檢查硬編碼路徑..."
if grep -r "/root/.openclaw" /Users/adai/.openclaw/workspace \
  --include="*.py" --include="*.sh" 2>/dev/null | grep -v ".bak"; then
    echo "❌ 發現未替換的 /root/.openclaw 路徑"
else
    echo "✅ 路徑替換完成"
fi

# 2. 檢查瀏覽器
echo "2. 檢查 Chrome 路徑..."
if [ -f "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" ]; then
    echo "✅ Chrome 已安裝"
else
    echo "❌ Chrome 未找到，請安裝"
fi

# 3. 檢查關鍵腳本語法
echo "3. 檢查 Python 腳本語法..."
for script in /Users/adai/.openclaw/workspace/scripts/*.py; do
    if python3 -m py_compile "$script" 2>/dev/null; then
        echo "  ✅ $(basename $script)"
    else
        echo "  ❌ $(basename $script) - 語法錯誤"
    fi
done

# 4. 檢查服務
echo "4. 檢查 News API 服務..."
if curl -s http://127.0.0.1:8888/health 2>/dev/null; then
    echo "✅ News API 運行中"
else
    echo "❌ News API 未運行"
fi

# 5. 檢查配置文件
echo "5. 檢查配置文件..."
if [ -f "/Users/adai/.openclaw/openclaw.json" ]; then
    echo "✅ openclaw.json 存在"
    # 檢查 Chrome 路徑
    if grep -q "Google Chrome.app" /Users/adai/.openclaw/openclaw.json; then
        echo "✅ Chrome 路徑已配置為 macOS"
    else
        echo "⚠️  Chrome 路徑可能需要更新"
    fi
else
    echo "❌ openclaw.json 不存在"
fi

echo "=== 驗證完成 ==="

6.2 功能測試清單

  • 發送消息給原有 Bot，確認 Mac Mini 能收到並回復

第七階段：切換上線

切換時間線

Mac Mini 配置完成，使用原有 Bot Token；Linux 配置新 Bot Token。
T+1: 功能測試
測試所有功能正常，Frank 開始使用 Mac Mini 上的 Bot。

兩台機器同時運行，但使用不同 Bot，互不影響。
T+3: 停用舊機器（可選）
確認 Mac Mini 穩定後，停止 Linux 上的 OpenClaw。

停用 Linux OpenClaw

# 在 Linux 上執行
# 停止 OpenClaw
openclaw gateway stop

# 停止 News API 服務
sudo systemctl stop news-api
sudo systemctl disable news-api

  • 已記錄新 Bot Token
  • Mac Mini 已安裝 OpenClaw
  • Mac Mini 已安裝 Chrome、Python、Gunicorn

遷移中檢查

  • 數據已成功傳輸到 Mac Mini
  • 已執行路徑批量替換
  • 已更新 openclaw.json 中的 Chrome 路徑
  • 已配置正確的 Bot Token（Mac 用舊，Linux 用新）
  • 已創建 launchd 服務文件
  • 已加載並啟動 News API 服務

遷移後檢查

  • Frank 可以正常與 Mac Mini 上的 Bot 對話
  • web_search 工具正常工作
  • browser 工具正常工作
  • News API 可以訪問
  • Cron 任務正常執行
  • 小二（Xiaoer）正常運作
  • 所有自定義腳本正常運行

特別注意事項

💡
  • 外部項目路徑：如果有引用 /root/project 下的項目（如博客源碼），需要在 Mac 上創建相同的目錄結構或遷移那些項目。
  • Git 倉庫：workspace 是 git 倉庫，遷移後檢查 remote 配置：git remote -v
  • 文件權限：可能需要調整腳本權限：chmod +x /Users/adai/.openclaw/workspace/scripts/*.sh
  • 防火牆：確保 Mac Mini 的防火牆允許所需端口（如 8888 for News API）
