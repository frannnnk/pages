GET /news 需要 Token

獲取每日新聞數據。支持按分類篩選，數據每日自動更新。

Query 參數
參數 類型 必填 說明
token string 是 API 認證 Token
category string 否 新聞分類：world, china, hongkong, gds, ai
請求示例
curl "https://code.frank.hk/news-api/news?token=YOUR_API_TOKEN&category=gds"
響應示例
{
  "status": "success",
  "category": "gds",
  "last_update": "2026-02-25T06:00:01.993521",
  "count": 4,
  "data": [
    {
      "id": "gds_2026-02-25_001",
      "category": "gds",
      "title": "GDS Holdings Announces Q4 2025 Results",
      "title_zh": "萬國數據公布 2025 年第四季度業績",
      "summary": "萬國數據今日公布第四季度財報...",

  ]

GET /visit 公開

記錄頁面訪問並返回該文章的總訪問量。同個 IP 在 10 分鐘內重複訪問不會重複計數。

Query 參數
參數 類型 必填 說明
slug string 是 文章 slug（URL 最後一節）
請求示例
curl "https://code.frank.hk/news-api/visit?slug=jump-desktop-remote-mac-mini"
響應示例
{
  "slug": "jump-desktop-remote-mac-mini",
  "views": 4,
  "is_new_visit": false,
  "timestamp": "2026-02-25T14:12:30.235502"
}
說明

is_new_visit 表示此次請求是否被計為新訪問。 同個 IP 在 10 分鐘內訪問同一篇文章，is_new_visit 會返回 false。

GET /stats/ranking 公開

獲取所有文章的訪問量排行榜，按訪問量從高到低排序。

Query 參數
參數 類型 必填 說明
limit integer 否 返回前 N 條記錄。不傳則返回全部。
請求示例
# 獲取全部排行榜
curl "https://code.frank.hk/news-api/stats/ranking"

# 只顯示前 5 名
curl "https://code.frank.hk/news-api/stats/ranking?limit=5"
響應示例
{
  "status": "success",
  "total_slugs": 11,
  "total_views": 25,
  "returned": 5,
  "ranking": [
    {"rank": 1, "slug": "nft-erc1155", "views": 8},
    {"rank": 2, "slug": "openclaw-telegram-streaming-setup-guide", "views": 4},
    {"rank": 3, "slug": "jump-desktop-remote-mac-mini", "views": 4},
    {"rank": 4, "slug": "openclaw-device-token-mismatch-fix", "views": 2},
    {"rank": 5, "slug": "openclaw-day6-mystery", "views": 1}
  ],
  "timestamp": "2026-02-25T14:32:58.909317"
}
GET /stats 公開

獲取所有文章的原始訪問統計數據（未排序）。

請求示例
curl "https://code.frank.hk/news-api/stats"
響應示例
{
  "status": "success",
  "visits": {
    "nft-erc1155": 8,
    "openclaw-telegram-streaming-setup-guide": 4,
    "jump-desktop-remote-mac-mini": 4
  },
  "total_slugs": 11,
  "total_views": 25,
  "timestamp": "2026-02-25T14:32:58.909317"
}
GET /stats/:slug 公開

獲取指定文章的訪問量。

Path 參數
參數 類型 必填 說明
slug string 是 文章 slug
請求示例
curl "https://code.frank.hk/news-api/stats/nft-erc1155"
響應示例
{
  "status": "success",
  "slug": "nft-erc1155",
  "views": 8,
  "timestamp": "2026-02-25T14:32:58.909317"
}

    "total_views": 25
  }
